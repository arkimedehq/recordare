# Dev set — entity memory with own content (WORK_PLAN 8.5, NOT blind)

Written by the engine developer for 8.5 (entity agent in the first person, D50). One shared assistant of a bike shop
(`ciclofficina`, an entity memory). 8 sessions, 5–10 Oct 2026, Europe/Rome; 15 questions asked on 10 Oct by someone
not identified.

What it exercises: content given to the agent to keep (`own: true` — a supplier price list, an owner's note), the
assistant's own actions (a reminder, a rental extension), speakers identified only in the conversation ("sono Sara"),
a hand-over (Sara → Luca), two unidentified speakers (a finished repair, a personal complaint), two people named Marco
(the supplier Marco Ferri, Marco of the gravel group — the assistant asks which), an English customer, a price change
reported second-hand.

Not blind: never use it to confirm a decision (blind8 does that).
